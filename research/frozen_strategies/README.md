# Frozen Strategies

本目录保存已经冻结的策略配置和参考结果，仅用于历史复现、样本外验证、信号观察和人工复核。

## 隔离规则

- 不作为 Transformer、RNN、线性模型或因子消融的训练输入。
- 不从本目录读取模型权重、标准化参数、标签或特征列。
- 不把本目录中的参考收益用于选择超参数、因子组合或模型结构。
- 后续训练统一使用 `output/research/model_comparison/` 下的新实验目录。
- 新策略必须使用新的 `strategy_id` 和新的输出目录，不覆盖冻结版本。
- 只有在参数完全不变时，才允许用最新数据对冻结策略做独立样本外复测。
- 未经人工确认，不连接券商、不自动下单。
